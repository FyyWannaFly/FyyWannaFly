## About Me

Yo, I'm **Fyy**.

I build things around **Roblox scripting**, **automation**, **route playback systems**, **Discord-driven license platforms**, and **native tooling** for private runtimes.
Most of my projects are practical systems that combine UI, backend validation, local tooling, and deployment-ready workflows.

## What I Actually Work On

- **Roblox Luau script ecosystems** with polished UI and documented feature sets
- **Route recording and playback systems** built around reusable JSON track data
- **License-first infrastructure** using Discord bots, REST APIs, and validation flows
- **Desktop launchers and native runtime tooling** for gated distribution and controlled delivery
- **Community-oriented automation tools** that reduce repeated manual work

## Featured Public Projects

### [FyyLuaCollection](https://github.com/FyyWannaFly/FyyLuaCollection)
Curated Roblox Luau script hub with encrypted release builds, per-script docs, and WindUI / Fluent-based tooling.

### [FyyMountHub](https://github.com/FyyWannaFly/FyyMountHub)
Mount-focused Roblox utility hub with authentication flow, player tools, auto-walk playback, and route controls.

### [TrackMountRoblox](https://github.com/FyyWannaFly/TrackMountRoblox)
Large JSON-based route archive for movement playback, route sharing, and reusable track datasets.

### [FyyLicensesShowcase](https://github.com/FyyWannaFly/FyyLicensesShowcase)
Public architecture showcase for a licensing platform that connects Discord bot workflows, REST API validation, and Roblox loaders.
