I build systems around **Roblox scripting**, **automation**, **route playback workflows**, **Discord-managed licensing**, and **native runtime tooling**.

Most of my work is practical: tools that get used, private infrastructure that actually ships, and project stacks that connect game-side scripts, backend validation, and desktop delivery.

## Focus

- **Luau / Lua tooling** for Roblox script ecosystems
- **JSON route archives** and movement playback systems
- **Discord + API license flows** for gated access and distribution
- **Native C / C++ launcher work** for private runtime delivery

## Selected Work

### Public

| Project | What it is |
| --- | --- |
| [FyyLuaCollection](https://github.com/FyyWannaFly/FyyLuaCollection) | Curated Luau script hub with encrypted releases, per-script docs, and UI-driven tooling. |
| [FyyMountHub](https://github.com/FyyWannaFly/FyyMountHub) | Mount-focused Roblox utility hub with auth flow, player tools, and route playback controls. |
| [TrackMountRoblox](https://github.com/FyyWannaFly/TrackMountRoblox) | JSON-based route archive for movement playback, track sharing, and reusable path datasets. |
| [FyyLicensesShowcase](https://github.com/FyyWannaFly/FyyLicensesShowcase) | Public architecture write-up for a Discord bot + REST API + Roblox loader licensing platform. |

### Private

- **FyyXPW** - native runtime-focused private system work
- **FyyXPW_Injector** - authenticated launcher and gated injection flow
- **FyyPW-License** - device-bound license platform and admin workflow infrastructure
- Additional **Visual Studio / native experiments** around runtime helpers, UI tests, and delivery tooling
